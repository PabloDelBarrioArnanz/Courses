
# Node.JS

No es un lenguaje de programación
No es un framework
No es una librería

Es un entorno de ejecución para JavaScript (donde se puede ejecutar JS fuera del navegador) construido sobre el motor V8 de Google Chrome
Es asíncrono, con entrada y salida de datos, con arquitectura orientada a eventos y con un solo hilo de ejecución (single thread)
Es multiplataforma (Windows, Linux, MacOS)
